## creating modules and functions on a topic "Введение в ООП"

### module: product.py
Класс Product, доработана функциональность сложения таким образом, чтобы можно было складывать товары только из одинаковых классов продуктов и он определяет следующие свойства:
* название (name),
* описание (description),
* цена (price),
* количество в наличии (quantity).
- Геттер для приватного атрибута products с использованием декоратора @property, для цены и сеттер для проверки цены, она не должна быть нулевая или отрицательная;
- Класс-метод new_product() с помощью декоратора @classmethod, который добавляет новый продукт из словаря;
- В класс Product дополнен магический методом __str__, который возвращает строку: Название продукта, X руб. Остаток: X шт. и рассчитывает общее количество товаров на складе (
quantity) для каждого продукта в приватном атрибуте products;
- В класс Product добаален магический метод сложения __add__, который принимает два аргумента: self и второй объект, он возвращает сумму произведений цены на количество у двух объектов;

### module: category.py
Класс Category, доработан метод add_product, который добавляет продукт в категорию таким образом, чтобы не было возможности добавить вместо продукта или его наследников любой другой объект и определет следующие свойства:
* название (name),
* описание (description),
* список товаров категории (products);
- В класс Category добавлен магический метод __str__, который возвращает строку: Название категории, количество продуктов: X шт.
- Геттер products, с использованием декоратора @property, который возвращает строку со списком продуктов в отформатированном виде;
- Класс-метод total_quantity_all_categories с помощью декоратора @classmethod, который возвращает общее количество товаров во всех категориях;
- В класс Category добаален класс-метод сложения add_product(), который принимает два аргумента: self и второй объект и принимает только объекты Product, Smartphone или LawnGrass
